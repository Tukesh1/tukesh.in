### 🛠 Installation & Setup

#### *Prerequisites*
- Node.js 18+ 
- npm or yarn

#### *Clone & Install*
```bash
# Clone the repository
git clone https://github.com/tukesh1/tukesh.in.git

# Navigate to project directory
cd tukesh.in

# Install dependencies
npm install
```

#### *Development*
```bash
# Start development server
npm run dev

# Open http://localhost:3000
```

#### *Build & Deploy*
```bash
# Build for production
npm run build

# Start production server
npm start

# Lint code
npm run lint
```

### Running this Portfolio in Docker

#### 1. Build the Docker Image
Build your Docker image with the following command:

```bash
docker build -t tukesh.in .
```
Run the container and map it to port 3000:
```bash
docker run -p 3000:3000 tukesh.in .
```
You can now access this portfolio at http://localhost:3000
